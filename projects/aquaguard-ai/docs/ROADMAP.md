# Roadmap

## 当前：v4.0 Alpha 工程基线

- [x] 配置、领域模型、风险融合、连续帧确认
- [x] 事件 API、内存事件存储、测试与 CI
- [x] 合并时序融合、多摄像头融合、Pool BEV、未来风险预测和独立安全监督器
- [x] 像素坐标到泳池坐标的 Homography 投影接口
- [x] 模拟视觉观测适配器和确定性回放测试
- [x] 无全局身份时隔离相机本地轨迹，避免错误跨镜融合
- [x] USB/文件/RTSP 帧源、统一时间戳和有界重连退避
- [x] 视频帧到世界模型的可替换分析器运行链路
- [x] 内存环形帧缓冲和报警前后证据窗口
- [x] 可替换证据编码端口、原子清单持久化与 SHA-256 校验
- [ ] 帧像素视频编码与长期存储策略
- [ ] 稳定多人跟踪与检测/Pose 关联
- [ ] 每个摄像头的泳池 ROI 和水面标定
- [ ] PostgreSQL 事件、证据片段和审计日志
- [ ] MQTT/IP 音箱适配器与报警升级策略
- [ ] Web 监控台

## 商业试点前的硬门槛

- 真实/模拟数据集与标注规范
- 按场景统计的召回率、误报率、报警延迟和跟踪丢失率
- 遮挡、反光、夜间、拥挤、断流和断电测试
- 人工接管、故障降级、设备巡检与演练流程
- 隐私、安全、录像留存与当地法规审查

未满足以上门槛前，不得宣称系统可无人值守或可替代救生员。

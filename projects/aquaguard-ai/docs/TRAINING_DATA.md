# 时序训练数据集构建

当前实现解决“哪些录像和片段有资格进入训练集”，不负责下载第三方视频，也不执行视频转码或模型训练。

## 输入

`aquaguard-build-training-dataset` 接受三个输入文件：

1. `recordings.jsonl`：每行一个 `TrainingRecordingSource`。包含本地录像路径和摘要、场馆/场次/摄像头、视频基本参数、采集时间、摄像头标定摘要、使用权证明摘要、同意证明摘要和商业训练许可。包含未成年人时还必须提供监护同意证明摘要。
2. `episodes.jsonl`：每行一个已完成独立复核的行为片段。包含录像和轨迹、去标识参与者组、起止时间、危险判断、场景代码、标注协议摘要和已解决标注摘要。
3. `policy.json`：前后时序上下文、最短/最长片段和训练/验证切分比例。

摘要字段只绑定证据，不能替代对原始授权文件、同意范围和当地法规的人工审查。

## 构建

```bash
aquaguard-build-training-dataset \
  recordings.jsonl \
  episodes.jsonl \
  policy.json \
  temporal-dataset-v1.json \
  --name temporal-dataset-v1 \
  --split-seed frozen-split-v1 \
  --created-at 2026-07-21T00:00:00+00:00
```

输出是不可含机器本地源路径的规范化 JSON 清单，包含每个训练片段的准确边界、输入录像/标定/标注摘要和固定数据分区。可用清单 SHA-256 绑定训练运行、模型包和评估报告。

## 失败关闭规则

- 录像文件不存在、摘要不匹配或未明确允许商业训练时拒绝。
- 缺少权利、同意、标定或已解决标注摘要时拒绝。
- 未成年人录像缺少监护同意证明时拒绝。
- `uncertain` 标签、越界片段、过短/过长片段和未被标注使用的录像拒绝。
- 至少需要三个场馆；整个场馆和录像只能属于一个分区。
- 同一去标识参与者组不得跨训练、验证和测试分区。

这些约束避免相邻视频片段、同一场馆背景或同一参与者出现在不同分区造成虚高指标。
